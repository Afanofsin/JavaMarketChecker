User Guide

Here is the API endpoint that return only JSON:
/api/search.
params = {"weaponName", "skinName", "limiter" - for Weapon Skin Search.
params = {"findType", "containerName", "limiter"} - for Container Search.

findType - can be equal to "All", "One", "Several"
If "All", other parameters are not needed. If "Several", containerName can be blank. If "One", limiter can be blank

Database endpoints:
/api/search/allcases
/api/search/allskins

Visual Endpoints:
/search/cases
/search/skins
